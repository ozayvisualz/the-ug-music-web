TheUgMusic Platform Guide

Stream, download, and discover the best Ugandan music. Built for artists and listeners across Uganda and beyond.

1. Platform Overview

TheUgMusic is a complete music streaming and discovery platform built specifically for Ugandan music. It connects listeners with local artists through a modern streaming experience comparable to Spotify and Apple Music.

Core Applications

  • Listener Web App — theugmusic.com — Stream, discover, and download music
  • Listener Mobile App — iOS/Android via Expo — Full native streaming experience
  • Artist Portal — Upload music, track earnings, manage profile
  • Admin Dashboard — Platform management, moderation, analytics

2. For Listeners

Music Discovery

  • Home — Personalized dashboard with trending, new releases, Made For You mixes
  • Discover — Browse by genre, mood, trending searches
  • Made in Uganda — Curated collections: Trending in Kampala, Lugaflow, Dancehall, Gospel Hits, Party Mixes, Radio Charts, Editor's Picks, Hidden Gems
  • Radio — Genre and mood-based stations (Afrobeats, Dancehall, Gospel, Road Trip, Chill & Relax)
  • Search — Full-text search across songs, artists, albums, playlists, genres, and moods with typo tolerance

Playback & Library

  • Full Music Player — Large artwork, seek bar, lyrics, queue, shuffle, repeat
  • Mini Player — Always-on floating bar with play/pause and skip
  • Library — Liked songs, playlists, downloads, listening history
  • Continue Listening — Resume from where you left off across devices

Personalization

  • Mood Onboarding — Choose 28 mood categories on signup (Chill, Party, Lugaflow Heat, Dancehall Energy, Gospel Worship, etc.)
  • New Releases — Filtered by your preferred moods and genres
  • Made For You — Daily Mix, Weekly Mix, personalized recommendations
  • Dark/Light Theme — System-aware or manual theme switching

3. For Artists

Artist Experience

  • Artist Name / Stage Name — Public identity separate from legal name
  • Upload Music — Upload songs with cover art, mood tags, genre, lyrics, behind-the-song story
  • Music Management — Edit, publish/unpublish, delete songs and albums
  • Verified Badge — Admin verification for authentic artists

Earnings & Analytics

  • Revenue Dashboard — Track streams, downloads, earnings in real-time
  • Revenue Splits — Streaming 70/30, Downloads 70/30, Tips 95/5, Merch 85/15, Tickets 90/10
  • Analytics — Streams by mood, downloads, radio plays, follower growth
  • Withdrawals — Request payouts via MTN Mobile Money, Airtel Money, or bank

4. For Admins

Platform Management

  • Dashboard — Total users, artists, songs, streams, revenue overview
  • Song Approval — Review and approve/reject uploaded songs
  • Artist Verification — Verify, feature, or suspend artists
  • User Moderation — NEW Ban, suspend, restrict, or restore user accounts with audit logs

Notifications & Communication

  • Send Notifications — Target All Users, Artists, Listeners, or Premium subscribers
  • Playlist Management — Create editorial playlists, feature content

6. Technical Architecture

Tech Stack

  • Frontend — Next.js 16, React 19, Tailwind CSS, tRPC
  • Mobile — Expo SDK 54, React Native, Reanimated, React Navigation
  • Backend — tRPC API, Next.js Server Actions, REST endpoints
  • Database — PostgreSQL via Prisma ORM
  • Storage — Firebase Storage + MinIO/S3
  • Auth — NextAuth, JWT tokens, OAuth (Google)
  • Payments — Flutterwave integration
  • Real-time — Playback session sync, listening history

7. TheUgMusic Philosophy

Our mission is to create the definitive platform for Ugandan music — connecting artists with listeners, supporting local talent, and building a sustainable music ecosystem. Every feature is designed with Uganda in mind: from the genres and moods to the payment methods and curated playlists.
